      Conecta tu Claude con la oficina

      Todo funciona en tu ordenador: nada sale de localhost.

      1
      Abre la oficina con el servidor

      En la carpeta del proyecto:

      node server.js

      y entra en http://localhost:4747.

      2
      Claude Code → agente «Code» y su equipo

      Instala los hooks una sola vez y reinicia Claude Code:

      npm run hooks:install
      3
      Chat de claude.ai → agente «Chat»

      Instala la extensión Tampermonkey y añade el script userscript/claude-office.user.js. Al enviar un mensaje en claude.ai, «Chat» se pone a trabajar.

      4
      Cualquier otra cosa (n8n, scripts…) 
      curl -X POST localhost:4747/event -H "Content-Type: application/json" \
  -d '{"source":"chat","kind":"prompt","prompt":"Hola oficina"}'
